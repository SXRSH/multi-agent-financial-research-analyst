# Multi-Agent Financial Research Analyst

> An enterprise-grade multi-agent financial research platform built using Google Agent Development Kit (ADK), Gemini, FastAPI, and React.

---

## Overview

This project automates equity research by coordinating multiple AI agents that independently gather, analyze, and synthesize financial information into a structured investment report.

Instead of relying on a single LLM, the system uses specialized agents working together under a Coordinator Agent.

---

## Problem Statement

Financial analysts spend significant time collecting:

- Financial statements
- Company news
- Annual reports
- Peer comparisons
- Investment insights

This platform automates the workflow and produces a comprehensive investment thesis.
